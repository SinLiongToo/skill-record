⚡ 方法 1：執行一鍵自動掃描同步腳本 (最推薦)

我們已為您撰寫了專屬的自動同步腳本 sync_skills.py。它會全自動掃描您的 Antigravity 全域目錄 (~/.gemini/config/skills) 與 所有專案內的技能目錄 (.claude/skills, .agents/skills, .agent/skills, .gemini/skills, skills)，並比對應用專案名稱，一鍵自動同步至 skills_data.json 與前端介面！

python sync_skills.py
📝 方法 2：在 Web 介面直接新增或編輯

點擊右上角的「➕ 記錄新技能」或卡片上的「✏️ 編輯」按鈕，直接在網頁表單中修改名稱、生態來源（Antigravity 或 Claude）、應用專案、使用指引與架構，資料會立即儲存於瀏覽器的 localStorage，關閉或重新整理網頁都不會遺失。

💾 方法 3：JSON 匯出備份與跨電腦還原

點擊頂部的「💾 匯出」可將整個技能庫下載為包含 39+ 項技能與關聯專案的完整 JSON 備份檔。換電腦或跨瀏覽器時，只要點擊「📂 匯入」即可秒級載入完整技能庫。
